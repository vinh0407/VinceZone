# 10 Super Skills cho AI Agents & Engineers

Bảng tổng hợp 10 kỹ năng siêu việt (Super Skills) giúp AI đạt hiệu suất lập trình, xử lý công việc và tương tác ở đẳng cấp cao nhất:

| # | Skill | Tác dụng chính | Khi nào dùng |
|---|-------|----------------|--------------|
| 1 | **Anthropic Skills** | Tài liệu, PDF, spreadsheet, slides, thiết kế | Làm việc với tài liệu, trích xuất cấu trúc và phân tích báo cáo |
| 2 | **Superpowers** | Quy trình Spec → Plan → TDD → Review | Làm feature lớn, kiến trúc dự án từ con số 0 |
| 3 | **Karpathy Skills** | Code đơn giản, ít abstraction, suy nghĩ trước khi code | Tránh AI viết code rườm rà, lạm dụng design pattern không cần thiết |
| 4 | **Real Engineers** | Engineering workflow, debugging, testing, review | Xây/sửa project thực tế, truy tìm bug gốc và tối ưu hóa hệ thống |
| 5 | **UI/UX Pro Max** | UI/UX, responsive, accessibility, design system | Làm frontend/mobile, tối ưu trải nghiệm người dùng đa thiết bị |
| 6 | **Caveman** | Output ngắn, giảm lan man/token | Muốn agent giao tiếp súc tích, đi thẳng vào đáp án và code |
| 7 | **Addy Osmani Skills** | Frontend engineering, performance, production quality | Tối ưu web, giảm First Input Delay, Largest Contentful Paint, Core Web Vitals |
| 8 | **Taste Skill** | Visual taste, typography, hierarchy, composition | Làm giao diện đẹp, thẩm mỹ cao, tránh UI generic |
| 9 | **Awesome Claude Skills** | Kho tổng hợp để tìm thêm skills/tools | Muốn mở rộng skill và tìm công cụ tự động hóa chuyên biệt |
| 10 | **I Have ADHD** | Output dễ đọc, ngắn, rõ, actionable | Làm việc với agent lâu dài, cần checklist ngắn gọn và từng bước cụ thể |
